Вирусология

Что такое вирус?

Вирус — неклеточная форма жизни. Он проявляет свойства живого только внутри клетки-хозяина. Вне клетки вирус существует в виде вириона (инертная частица).

Строение вириона

  • Генетический материал: ДНК или РНК (одно- или двуцепочечная).
  • Капсид: белковая оболочка, защищающая геном.
  • Суперкапсид (у некоторых): липидная мембрана, «украденная» у клетки-хозяина при выходе.

Жизненный цикл (на примере бактериофага)

  1. Адсорбция: вирус прикрепляется к рецепторам на поверхности клетки.
  2. Проникновение: впрыскивание нуклеиновой кислоты в клетку (или эндоцитоз).
  3. Синтез: клетка перестает работать на себя и начинает производить копии вируса.
  4. Сборка: новые вирионы собираются из синтезированных компонентов.
  5. Выход: клетка лопается (лизис) или вирусы отпочковываются, истощая клетку.

Примеры

ВИЧ: РНК-вирус, поражает иммунные клетки. Грипп: РНК-вирус с высокой изменчивостью. Бактериофаг Т4: классический объект молекулярной биологии.

Генетика

Процессы с ДНК

ДНК — матрица для хранения и передачи информации. Основные процессы:

  • Репликация: удвоение ДНК перед делением клетки. Происходит по полуконсервативному принципу (каждая новая молекула содержит одну старую и одну новую цепь). Фермент: ДНК-полимераза.
  • Транскрипция: синтез РНК на матрице ДНК. Фермент: РНК-полимераза. Это первый этап реализации генетической информации.
  • Репарация: исправление ошибок и повреждений ДНК. Критически важна для предотвращения мутаций.

Закономерности наследственности и изменчивости

Наследственность — способность организмов передавать признаки потомкам. Изменчивость — способность приобретать новые признаки.

Типы изменчивости

  • Наследственная (генотипическая): затрагивает ДНК и передается по наследству.
  • Ненаследственная (фенотипическая/модификационная): изменения под действием среды (например, загар), ДНК не меняется.

Мутации

Мутации — это стойкие изменения генетического материала.

Классификация мутаций

  • Генные: изменение последовательности нуклеотидов в гене (замена, вставка, выпадение). Пример: серповидноклеточная анемия.
  • Хромосомные: изменение структуры хромосом (делеция, дупликация, инверсия, транслокация).
  • Геномные: изменение числа хромосом (полиплоидия, анеуплоидия). Пример: синдром Дауна (трисомия по 21-й паре).

Мутагены: факторы, вызывающие мутации (УФ-излучение, радиация, химические вещества, вирусы).

Клеточная теория и строение клеток

Основные положения клеточной теории

  • Клетка — элементарная единица строения, жизнедеятельности и развития всех живых организмов.
  • Клетки всех организмов гомологичны (сходны по строению и химическому составу).
  • Новые клетки образуются только путем деления исходной (материнской) клетки.
  • Многоклеточный организм — это сложная система взаимодействующих клеток.

Клетки по царствам

Бактерии (Прокариоты)

Нет ядра. ДНК кольцевая, лежит прямо в цитоплазме (нуклеоид). Нет мембранных органоидов. Есть клеточная стенка (муреин). Мелкие рибосомы (70S). Пример: кишечная палочка.

Растения (Эукариоты)

Есть ядро и мембранные органоиды. Специфично: клеточная стенка (целлюлоза), крупная вакуоль с клеточным соком, пластиды (хлоропласты для фотосинтеза). Запасное вещество — крахмал.

Грибы (Эукариоты)

Есть ядро. Специфично: клеточная стенка (хитин), нет пластид. Гетеротрофы (питаются готовыми органическими веществами). Запасное вещество — гликоген. По строению близки к животным.

Животные (Эукариоты)

Есть ядро. Специфично: нет клеточной стенки (есть гибкая мембрана), нет пластид. Есть центриоли (участвуют в делении). Запасное вещество — гликоген. Гетеротрофы.
